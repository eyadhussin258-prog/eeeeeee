# 🤖 Discord Bot لسيرفر 𝐏𝐞𝐫𝐟𝐞𝐜𝐭 𝐂𝐅𝐖

## 📋 المميزات

### 🎯 **الوظائف الأساسية**
- **إدارة التقديمات**: قبول، رفض، مراجعة
- **إدارة السيارات**: إضافة، تعديل، حذف
- **الإعلانات**: إرسال إعلانات للسيرفر
- **الإحصائيات**: عرض عدد اللاعبين والأعضاء
- **التحكم الكامل**: صلاحيات المالك فقط

### 🛠️ **الأوامر المتاحة**
```
!stats          - عرض إحصائيات السيرفر
!applications    - عرض قائمة التقديمات
!accept <رقم>   - قبول تقديم
!reject <رقم> <سبب> - رفض تقديم مع سبب
!addvehicle <اسم> <السعر> <الوصف> - إضافة سيارة
!announce <رسالة> - إرسال إعلان
!online <عدد>    - تحديث عدد اللاعبين
!help           - عرض المساعدة
```

## 🚀 التركيب والتشغيل

### 1. **تثبيت الحزم**
```bash
npm install discord.js dotenv
```

### 2. **إعداد المتغيرات**
```bash
# نسخ ملف الإعدادات
cp .env.example .env

# تعديل الملف
nano .env
```

### 3. **إعداد المتغيرات المطلوبة**
```env
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
CLIENT_ID=1496988349762900029
GUILD_ID=YOUR_SERVER_ID_HERE
```

### 4. **تشغيل البوت**
```bash
# للتطوير
npm run dev

# للإنتاج
npm start
```

## 🔧 الإعدادات المتقدمة

### **توصيل البوت بالسيرفر**
- البوت يحتاج صلاحيات:
  - `Administrator` للوصول الكامل
  - `Manage Server` لإدارة السيرفر
  - `Send Messages` لإرسال الرسائل

### **قنوات مخصصة**
- `#announcements` للإعلانات
- `#admin-commands` لأوامر الإدارة
- `#applications` لإشعارات التقديمات

## 📊 البيانات

### **تخزين البيانات**
- يتم حفظ البيانات في ملف `server_data.json`
- يدعم:
  - التقديمات وحالتها
  - السيارات المتاحة
  - الإعلانات السابقة
  - إحصائيات السيرفر

### **المزامنة التلقائية**
- تحديث عدد اللاعبين كل 5 دقائق
- مزامنة البيانات مع الموقع
- إشعارات فورية للتغييرات

## 🛡️ الأمان

### **حماية البوت**
- التحقق من صلاحيات المالك
- منع الأوامر من المستخدمين العاديين
- تسجيل جميع الأنشطة
- معالجة الأخطاء بأمان

### **نصائح الأمان**
1. **لا تشارك الـ Bot Token** مع أي شخص
2. **استخدم متغيرات البيئة** (.env)
3. **فعل التحقق من خطوتين** (2FA) في ديسكورد
4. **حدد الصلاحيات** بشكل دقيق للبوت

## 🔗 التكامل مع الموقع

### **API Endpoint**
البوت يوفر API للتواصل مع الموقع:
```
GET /api/stats - إحصائيات السيرفر
POST /api/applications - إدارة التقديمات
POST /api/vehicles - إدارة السيارات
POST /api/announcements - إدارة الإعلانات
```

### **التحديثات المباشرة**
- البوت يرسل تحديثات للموقع عند:
  - قبول أو رفض التقديمات
  - إضافة سيارات جديدة
  - تغيير عدد اللاعبين
  - إرسال إعلانات جديدة
