# Perfect CFW Control Panel

لوحة تحكم احترافية مستوحاة من تصميم LEGACY RP مع علامة تجارية خاصة بـ Perfect CFW.

## المميزات

### 🎨 التصميم والواجهة
- واجهة عربية RTL بالكامل
- تصميم عصري وأنيق بألوان داكنة
- رسوم متحركة سلسة وتفاعلية
- دعم كامل للشاشات المختلفة (Responsive Design)

### 📊 لوحة التحكم
- **نظرة عامة**: إحصائيات مباشرة ورسوم بيانية
- **التحليلات**: إحصائيات مفصلة وأداء النظام
- **الإشعارات**: نظام إشعارات متقدم مع إدارة كاملة
- **النسخ الاحتياطي**: إدارة النسخ الاحتياطية والاستعادة
- **الأداء**: مراقبة استخدام الموارد وتحسين الأداء

### ⚡ المميزات التقنية
- تحديثات تلقائية في الوقت الفعلي
- رسوم بيانية تفاعلية باستخدام Chart.js
- نظام إشعارات متقدم
- أداء محسّن وتحميل سريع
- دعم كيبورد شورتكتس

## الهيكل التقني

```
perfect-cfw-control/
├── index.html          # الصفحة الرئيسية
├── css/
│   └── style.css       # ملفات التصميم
├── js/
│   └── script.js       # ملفات JavaScript
└── README.md           # ملف التوضيح
```

## التقنيات المستخدمة

- **HTML5**: بنية الصفحات الحديثة
- **CSS3**: تصميم متقدم مع CSS Variables و Grid/Flexbox
- **JavaScript ES6+**: وظائف تفاعلية حديثة
- **Chart.js**: رسوم بيانية تفاعلية
- **Font Awesome**: أيقونات احترافية
- **Google Fonts**: خط Tajawal العربي

## التثبيت والتشغيل

### المتطلبات
- متصفح حديث (Chrome, Firefox, Safari, Edge)
- لا يتطلب خادم محلي (يمكن تشغيله مباشرة)

### الخطوات

1. **تحميل الملفات**
   ```bash
   git clone <repository-url>
   cd perfect-cfw-control
   ```

2. **تشغيل المشروع**
   - افتح ملف `index.html` مباشرة في المتصفح
   - أو استخدم خادم محلي للتطوير:
     ```bash
     # باستخدام Python
     python -m http.server 8000
     
     # أو باستخدام Node.js
     npx serve .
     ```

3. **الوصول إلى لوحة التحكم**
   - افتح `http://localhost:8000` في المتصفح

## الاستخدام

### التنقل الرئيسي
- استخدم القائمة العلوية للتنقل بين الأقسام الرئيسية
- القائمة الجانبية للوصول إلى الصفحات المختلفة
- جميع الروابط تفاعلية مع رسوم متحركة سلسة

### المميزات التفاعلية
- **الرسوم البيانية**: عرض تفاعلي للبيانات والإحصائيات
- **الإشعارات**: نظام إشعارات فوري مع إدارة كاملة
- **النسخ الاحتياطي**: إنشاء وإدارة النسخ الاحتياطية
- **المراقبة**: متابعة أداء النظام في الوقت الفعلي

### اختصارات لوحة المفاتيح
- `Ctrl/Cmd + K`: البحث السريع (قيد التطوير)
- `Escape`: إغلاق النوافذ المنبثقة

## التخصيص

### تغيير الألوان
يمكن تعديل الألوان الرئيسية عبر CSS Variables في `css/style.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --success-color: #10b981;
    /* ... */
}
```

### إضافة صفحات جديدة
1. أضف صفحة جديدة في `index.html`
2. أضف الرابط في القائمة الجانبية
3. أضف وظائف JavaScript في `js/script.js`

### تعديل البيانات
يمكن تعديل البيانات الظاهرة في الرسوم البيانية والإحصائيات عبر ملف `js/script.js`

## دعم المتصفحات

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## الأداء

- تحميل أولي سريع (< 2 ثانية)
- تحديثات تلقائية كل 30-60 ثانية
- استهلاك منخفض للذاكرة
- رسوم متحركة محسّنة بـ 60fps

## الأمان

- لا يوجد معالجة للبيانات الحساسة على العميل
- جميع الروابط آمنة
- حماية من XSS attacks
